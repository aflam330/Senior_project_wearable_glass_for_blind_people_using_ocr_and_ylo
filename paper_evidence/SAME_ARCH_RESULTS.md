# Same-architecture comparison: fixed 6-view training vs prefix training (JaalTaka)

Generated by `realtime_bangla_taka_detection/scripts/eval/write_same_arch_results.py` from saved test files.
Same PRMVT network, same note-disjoint split, same 208 test notes, seeds 42, 43, 44. Each run: 6 epochs, then 3 fine-tuning epochs; checkpoint chosen on validation only (`scripts/train/run_same_arch.py`, `configs/same_arch/`). Test accuracy is the first k views, threshold 0.5.

## Arms

| arm | training | files |
|---|---|---|
| fixed | 6 views only, per-count BN | `realtime_bangla_taka_detection/results/same_arch/fixed/s2/seed*/test_views` |
| fixed_shbn | 6 views only, one shared BN | `realtime_bangla_taka_detection/results/same_arch/fixed_shbn/s2/seed*/test_views` |
| prefix_shbn | prefixes 1-6 + single-view loss, one shared BN | `realtime_bangla_taka_detection/results/same_arch/prefix_shbn/s2/seed*/test_views` |
| prefix (PRMVT) | prefixes 1-6 + single-view loss, per-count BN | `realtime_bangla_taka_detection/results/qduig/prefix_ft/seed*/test_views_20260928` |

`prefix_shbn` differs from `fixed_shbn` in two settings at once (mixed view dropout and the 0.5 single-view loss), so it tests the prefix recipe as a whole, not each setting alone.
