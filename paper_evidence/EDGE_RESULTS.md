# Edge results

Pi 5 latency, FPS, CPU, RAM, temperature, and a 30-minute sustained run are NOT_MEASURED. This machine is a Windows laptop with an RTX 3050. No Raspberry Pi 5 was attached, so those numbers are not reported.

INT8 ONNX export of PRMVT, NDAL, and PRAVT was not run. A host-side ONNX timing would not be a Pi 5 measurement, so it is omitted rather than relabeled.

Seed-42 accuracy artifacts used for the paper are on this machine under `realtime_bangla_taka_detection/results/`. They are not edge measurements.
